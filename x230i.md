# X230i Homelab Setup

192.168.1.50 -- x230i.local --- usr

## 1. Hardware

**Server:** Lenovo ThinkPad X230i
**CPU:** Intel Celeron 877, 1.4 GHz, dual-core
**RAM:** 8 GB
**Storage:** Internal SSD + external Philips NTFS HDD

The X230i is being repurposed as a **headless home server**. It runs without a desktop environment and is managed remotely over SSH.

---

# 2. Operating System

Installed:

**Debian 13 Minimal**

During installation:

* No desktop environment
* No GNOME/KDE/Xfce
* SSH server enabled
* Standard system utilities enabled

The machine is configured to operate headlessly.

# 5. Windows PowerShell Shortcut

A custom PowerShell command was created so the server can be accessed using:

```powershell
x230i
```

The shortcut also supports a status command:

```powershell
x230i status
```

The status command SSHes into the X230i and displays:

* Server uptime
* Battery percentage
* Battery charging/discharging status

Current concept:

```powershell
function x230i { 
    param([string]$Command)

    if ($Command -eq "status") {
        ssh usr@x230i.local "echo '=== X230i ==='; uptime -p; echo -n 'Battery: '; cat /sys/class/power_supply/BAT0/capacity; echo -n '% ('; cat /sys/class/power_supply/BAT0/status; echo ')'"
    }
    else {
        ssh usr@x230i.local
    }
}
```

The PowerShell profile is located at:

```text
C:\Users\marti\OneDrive\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1
```

PowerShell execution policy was changed for the current user:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

# 6. Headless/Lid Configuration

Because the X230i is intended to operate as a headless server, closing the lid should not suspend the machine.

Edited:

```bash
sudo nano /etc/systemd/logind.conf
```

Configured:

```ini
HandleLidSwitch=ignore
HandleLidSwitchExternalPower=ignore
HandleLidSwitchDocked=ignore
```

The machine can therefore remain running with the lid closed.

# 8. NTFS Support

Installed NTFS support:

```bash
sudo apt install ntfs-3g
```

Created the mount point:

```bash
sudo mkdir -p /mnt/philips
```

Initially mounted the drive manually:

```bash
sudo mount -t ntfs-3g /dev/sdc1 /mnt/philips
```

The filesystem reported that it had not been safely closed by Windows and performed a filesystem fix.

After mounting, the existing files were verified:

```bash
ls /mnt/philips
```

All required files were present.

---

# 9. Automatic HDD Mounting

The user's Linux account is:

```text
usr
```

with:

```text
UID=1000
GID=1000
```

Added the following entry to:

```bash
/etc/fstab
```

```fstab
UUID=6A02981E0297ED77 /mnt/philips ntfs-3g uid=1000,gid=1000,umask=022,nofail,x-systemd.device-timeout=10 0 0
```

This makes the external HDD automatically mount at:

```text
/mnt/philips
```

after boot.

The configuration was tested by unmounting and remounting:

```bash
sudo umount /mnt/philips
sudo mount -a
```

Then verifying:

```bash
ls /mnt/philips
```

The files were still accessible.

A reboot was also performed and the configuration continued to work.

     ▼

```text

```

The share can then be mapped to a Windows drive letter such as:

```text

```

This will allow the external HDD to behave like a network drive while physically remaining connected to the X230i.

# 12. Important Safety Notes

The Philips HDD contains important existing data.

**Do not run the following against `/dev/sdc1`:**

```bash
mkfs
format
fdisk
parted
```

Do not reformat the drive.

The important identifiers are:

```text
Device: /dev/sdc1
Filesystem: NTFS
UUID: 6A02981E0297ED77
Mount point: /mnt/philips
Owner UID: 1000
Owner GID: 1000
```

The internal Debian drive is:

```text
/dev/sda
```

and should not be confused with the external Philips drive.
